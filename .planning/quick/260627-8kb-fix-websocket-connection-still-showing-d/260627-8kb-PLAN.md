# Quick Task 260627-8kb: Fix WebSocket connection still showing Disconnected

**Status:** Ready for planning
**Date:** 2026-06-27

## Problem
Frontend shows "Disconnected" because WebSocket cannot connect through Next.js proxy.

## Root Cause
- Frontend runs on port 3000
- Backend runs on port 8000
- Next.js rewrites only work for HTTP, not WebSocket
- WebSocket client connects to `ws://localhost:3000/api/v2/ws` which fails

## Solution
Make WebSocket client connect directly to backend port 8000.

## Tasks
1. Update `frontend-new/src/lib/websocket.ts` to use backend URL
2. Rebuild and restart Docker container
