- If `DATABASE_URL` starts with `postgresql+asyncpg://` or `postgresql://` → PostgreSQL mode
- If `DATABASE_URL` starts with `sqlite://` → SQLite mode (current behavior)
- Default: SQLite fallback to `account_manager.db`

**Changes to engine.py:**

1. Replace the module-level `engine = create_engine(DATABASE_URL)` with a factory function:
   - `_create_sync_engine(url: str)` — creates sync engine for both SQLite and PostgreSQL (using psycopg2 dialect for PG)
   - `_create_async_engine(url: str)` — creates async engine only for PostgreSQL URLs (using asyncpg dialect)
   - Keep `engine` as module-level sync engine for backward compatibility (all 94 call sites use `with Session(engine)`)

2. Add auto-detection function `_is_postgresql(url: str) -> bool`:
   - Returns True if url starts with `postgresql+asyncpg://` or `postgresql://` (but not `postgresql+psycopg2://`)
   - Returns False for `sqlite://` URLs

3. Add URL normalization for sync engine (per D-03: explicit `postgresql+asyncpg://` prefix):
   - If URL is `postgresql+asyncpg://...`, normalize to `postgresql+psycopg2://...` for sync engine
   - This allows existing sync `Session(engine)` code to work with PostgreSQL via psycopg2
   - Async engine preserves the `postgresql+asyncpg://` prefix as-is

4. Preserve ALL existing functions unchanged:
   - `_load_json()` — keep as-is
   - `_accounts_columns()` — keep as-is
   - `_ensure_column()` — keep as-is (SQLite-specific but harmless on PG)
   - `save_account()` — keep as-is
   - `init_db()` — keep as-is
   - `get_session()` — keep as-is

5. Add `DATABASE_URL` export (already exists, ensure it's in __init__.py)

- Add `_create_async_engine` to exports

- Keep all existing exports unchanged

| T-2-03 | Elevation of Privilege | test DB connection | low | accept | Tests use local SQLite by default; PostgreSQL tests require explicit env var — developer responsibility |
