   - `__init__(self, platform: str, requests_per_minute: int = 5)` — per-platform configurable limit
   - `allow(self) -> bool` — sliding window check, records timestamp if allowed
   - `wait_time(self) -> float` — seconds until next request allowed (0.0 if allowed now)

   - `reset(self)` — clear timestamps (for testing)
   - Store a `_platform: str` attribute for metrics correlation

2. **ProviderRateLimiter** — Per-provider rate limiting for SMS/captcha (per D-02):
   - `__init__(self, provider_type: str, provider_name: str, requests_per_minute: int = 10)` — provider_type is "sms" or "captcha"
   - `allow(self) -> bool` — same sliding window algorithm
   - `wait_time(self) -> float`
   - Internal `_timestamps: list[float]`
   - Store `_provider_type` and `_provider_name` for metrics correlation

3. **RateLimitMetrics** — Centralized metrics collection (per D-04):
   - `__init__(self)` — initializes counters
   - `_hits: dict[str, int]` — rate limit拒绝 count per limiter key (key = "platform:chatgpt" or "sms:herosms")
   - `_usage: dict[str, list[float]]` — recent request timestamps per limiter key (for current usage gauge)
   - `_throttles: dict[str, int]` — throttle event count per key
   - `record_hit(key: str)` — increment hit counter for a key
   - `record_throttle(key: str)` — increment throttle counter for a key
   - `record_usage(key: str)` — append timestamp to usage list, cleanup entries older than 60s
   - `get_metrics(self) -> dict` — return `{"hits": {...}, "usage": {...}, "throttles": {...}}` where usage values are counts of requests in last 60s
   - `reset(self)` — clear all counters (for testing)

4. **Module-level singleton**: `rate_limit_metrics = RateLimitMetrics()` — single shared instance

5. **Integration helper functions**:
   - `check_platform_limit(platform: str, metrics: RateLimitMetrics | None = None) -> bool` — creates/gets a PlatformRateLimiter for the platform, calls allow(), records metrics if metrics provided
   - `check_provider_limit(provider_type: str, provider_name: str, metrics: RateLimitMetrics | None = None) -> bool` — creates/gets a ProviderRateLimiter, calls allow(), records metrics

   Use a module-level `_platform_limiters: dict[str, PlatformRateLimiter]` and `_provider_limiters: dict[str, ProviderRateLimiter]` for singleton instances per platform/provider.
