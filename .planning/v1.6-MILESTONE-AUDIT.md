## Integration Issues

### Critical (BLOCKERs)

1. **POOL-03 BrowserPool orphaned**: The `BrowserPool` class in `core/turnstile_pool.py` is a well-implemented asyncio.Queue-based pool with acquire/release/close semantics. However, it is only imported in `tests/test_browser_pool.py`. The turnstile solver runs as a separate subprocess with its own browser management. No production code instantiates `BrowserPool`.

2. **RATE-01/02 Rate limiting never enforced**: `PlatformRateLimiter` and `ProviderRateLimiter` are fully implemented with sliding window algorithms, configurable limits, and metrics tracking. However, `check_platform_limit()` and `check_provider_limit()` are never called from any platform registration code, task execution code, or API endpoints. The entire rate limiting infrastructure is a dead module.

3. **RATE-03 No input data**: Since rate limiting is never enforced, `RateLimitMetrics` never receives `record_usage()`, `record_hit()`, or `record_throttle()` calls. The `/api/rate-limits` endpoint always returns `{"hits": {}, "usage": {}, "throttles": {}}`.

### Warnings

4. **Retry utility orphaned**: `core/utils/retry.py` exports `retry` decorator and `retry_with_backoff` function with exponential backoff support, but no production code uses them.

5. **Dead code in task_scheduler.py**: Three functions are duplicated between `task_repository.py` and `task_scheduler.py`. The scheduler versions are dead code, and `claim_next_runnable_task` there lacks the `priority` return key.

## Recommendations

### Option 1: Fix integration gaps (recommended)

Create a new phase to:
1. Integrate `BrowserPool` into turnstile solver or platform browser code
2. Add rate limit checks to platform registration flows
3. Remove dead code from task_scheduler.py
4. Integrate retry utility into HTTP client or task runner

### Option 2: Accept gaps and complete milestone

If the rate limiting and browser pooling features are intended for future use (e.g., when scaling to multiple instances), accept the current state and track integration as backlog items.
