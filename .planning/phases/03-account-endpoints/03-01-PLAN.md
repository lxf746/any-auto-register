  <action>
Create a new file `api/v2/accounts.py` containing a FastAPI APIRouter with prefix "/accounts" and tag "accounts".

Import and instantiate `AccountsService` from `application.accounts`. Import domain types: `AccountCreateCommand`, `AccountUpdateCommand`, `AccountQuery` from `domain.accounts`. Import `ApiResponse` from `api.v2.response`.

Define Pydantic request models in this file (following CONVENTIONS pattern):
- `AccountCreateRequest` with fields: platform (str), email (str), password (str), user_id (str=""), lifecycle_status (str="registered"), overview (dict={}), credentials (dict={}), provider_accounts (list[dict]=[]), provider_resources (list[dict]=[]), primary_token (str=""), cashier_url (str=""), region (str=""), trial_end_time (int=0)
- `AccountUpdateRequest` with Optional fields matching AccountUpdateCommand: password, user_id, lifecycle_status, overview, credentials, provider_accounts, provider_resources, replace_provider_accounts (bool=False), replace_provider_resources (bool=False), primary_token, cashier_url, region, trial_end_time
- `AccountImportRequest` with fields: platform (str), lines (list[str])

Endpoints (all return ApiResponse envelope):

1. `POST /` — create account
   - Accept `AccountCreateRequest` body
   - Map to `AccountCreateCommand`
   - Call `service.create_account(command)`
   - Return `ApiResponse(ok=True, data=result)`

2. `GET /{account_id}` — get account by ID
   - Path param: account_id (int)
   - Call `service.get_account(account_id)`
   - If None: raise HTTPException(404, "Account not found")
   - Return `ApiResponse(ok=True, data=result)`

3. `PATCH /{account_id}` — update account
   - Path param: account_id (int)
   - Accept `AccountUpdateRequest` body
   - Map to `AccountUpdateCommand` (only set non-None fields)
   - Call `service.update_account(account_id, command)`
   - If None: raise HTTPException(404, "Account not found")
   - Return `ApiResponse(ok=True, data=result)`

4. `DELETE /{account_id}` — delete account
   - Path param: account_id (int)
   - Call `service.delete_account(account_id)`
   - Return `ApiResponse(ok=True, data={"ok": True})`

5. `GET /stats` — account statistics
   - Call `service.get_stats()`
   - Return `ApiResponse(ok=True, data=result)`

6. `POST /import` — import accounts from text lines
   - Accept `AccountImportRequest` body (platform + lines)
   - Call `service.import_accounts(platform, lines)`
   - Return `ApiResponse(ok=True, data=result)`

Note: The existing `GET /accounts` list endpoint in `api/v2/router.py` will be removed from router.py and moved here as `GET /` on the accounts sub-router, for consistency. But since it already works and Phase 2 Summary confirms it, keep it in router.py for now to avoid unnecessary churn — the new accounts.py router handles all other operations.

Per D-03 and D-04 from CONTEXT.md, use existing AccountsService methods and domain types — do NOT create new business logic.
