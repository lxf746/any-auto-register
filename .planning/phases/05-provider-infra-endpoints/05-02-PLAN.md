<task type="auto">
  <name>Task 1: Create proxies endpoints</name>
  <files>api/v2/proxies.py</files>
  <action>
Create `api/v2/proxies.py` with an `APIRouter(prefix="/proxies", tags=["proxies"])`.

Import `ProxiesService` from `application.proxies`, `ProxyCreateCommand` and `ProxyBulkCreateCommand` from `domain.proxies`, and `ApiResponse` from `api.v2.response`.

Instantiate service: `_service = ProxiesService()`

Create seven endpoints:

1. `GET /` — calls `_service.list_proxies()`, returns `ApiResponse(ok=True, data=result)`
2. `POST /` — reads body into dict via `Request.json()`, creates `ProxyCreateCommand(url=body["url"], region=body.get("region", ""))`, calls `_service.create_proxy(command)`, returns `ApiResponse(ok=True, data=result)`
3. `POST /bulk` — reads body into dict via `Request.json()`, creates `ProxyBulkCreateCommand(proxies=body["proxies"], region=body.get("region", ""))`, calls `_service.bulk_create_proxies(command)`, returns `ApiResponse(ok=True, data=result)`
4. `DELETE /{proxy_id}` — calls `_service.delete_proxy(proxy_id)`, returns `ApiResponse(ok=True, data=result)`
5. `POST /{proxy_id}/toggle` — calls `_service.toggle_proxy(proxy_id)`, returns `ApiResponse(ok=True, data=result)`
6. `POST /check` — calls `_service.trigger_check()`, returns `ApiResponse(ok=True, data=result)`
7. `POST /scan` — reads body into dict via `Request.json()` (with defaults for target_count, test_timeout, region), calls `_service.scan_public_proxies(...)`, returns `ApiResponse(ok=True, data=result)`

Follow the exact pattern from `api/v2/accounts.py`: module docstring, imports, router instantiation, service instantiation, endpoint functions with ApiResponse envelope.

  <files>api/v2/sms.py</files>
  <action>
Create `api/v2/sms.py` with an `APIRouter(prefix="/sms", tags=["sms"])`.

Import `ApiResponse` from `api.v2.response` and `is_herosms_phone_cache_alive` from `core.sms.cache`.

Create two GET endpoints that return provider status and cache information:

1. `GET /herosms` — returns HeroSMS provider status:
   ```python
   @router.get("/herosms")
   def herosms_status():
       cache_alive = is_herosms_phone_cache_alive()
       return ApiResponse(ok=True, data={
           "provider": "herosms",
           "cache_alive": cache_alive,
           "status": "active" if cache_alive else "inactive"
       })
   ```

2. `GET /smsbower` — returns SmsBower provider status:
   ```python
   @router.get("/smsbower")
   def smsbower_status():
       return ApiResponse(ok=True, data={
           "provider": "smsbower",
           "status": "active"
       })
   ```

These endpoints expose basic provider status information. The actual SMS functionality is handled during registration flows, not through API endpoints.

Follow the same file structure pattern as `api/v2/health.py` (simple GET endpoints).
