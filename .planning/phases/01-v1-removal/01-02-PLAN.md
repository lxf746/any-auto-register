  <behavior>
    - api/v2/auth.py экспортирует: create_session, validate_session, destroy_session, _check_rate_limit, _sessions

    - validate_session(token) проверяет presence в _sessions dict
    - destroy_session(token) удаляет из _sessions
    - _check_rate_limit(ip) возвращает True если запрос разрешен, False если rate limited (5 попыток за 5 минут)
    - api/v2/router.py импортирует create_session и _check_rate_limit из api.v2.auth
    - api/v2/deps.py импортирует validate_session из api.v2.auth
    - api/v2/ws.py импортирует _sessions из api.v2.auth
    - core/auth.py импортирует validate_session из api.v2.auth (lazy import в dispatch)
  </behavior>
  <action>
1. Создать api/v2/auth.py — скопировать содержимое api/auth.py (строки 1-52: импорты, _sessions, _login_attempts, create_session, validate_session, destroy_session, _check_rate_limit). НЕ копировать роутер и эндпоинты — это v1 router, он удаляется.
2. В api/v2/router.py заменить:
   - `from api.auth import create_session` → `from api.v2.auth import create_session`
   - `from api.auth import _check_rate_limit` → `from api.v2.auth import _check_rate_limit`
3. В api/v2/deps.py заменить:
   - `from api.auth import validate_session` → `from api.v2.auth import validate_session`
4. В api/v2/ws.py заменить:
   - `from api.auth import _sessions` → `from api.v2.auth import _sessions`
5. В core/auth.py заменить оба lazy import (строки 45 и 53):
   - `from api.auth import validate_session` → `from api.v2.auth import validate_session`
   - `from api.auth import validate_session` → `from api.v2.auth import validate_session`
  </action>
