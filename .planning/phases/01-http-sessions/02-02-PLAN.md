<objective>
Implement HTTP session reuse via ManagedSession mixin, create a reusable browser context pool
extending the turnstile solver's asyncio.Queue pattern, and add pool metrics to the health endpoint.

Purpose: Currently 10+ platform clients create curl_cffi.Session per-request (never closed),
7 SMS/mailbox classes create requests.Session per-call, and ~15 browser call sites create
Playwright contexts on-demand. This wastes connections and file descriptors. Pool monitoring
gives visibility into resource usage.

Output: Session-reusing platform clients, a shared browser pool module, and health endpoint
with pool metrics.
</objective>

import asyncio
from core.turnstile_pool import BrowserPool

async def test():
    pool = BrowserPool(max_size=3)
    assert pool.qsize() == 0, 'Empty pool should have qsize 0'
    ctx1 = await pool.acquire()
    assert pool.qsize() == 0, 'Acquired context not in pool'
    await pool.release(ctx1)
    assert pool.qsize() == 1, 'Released context should be in pool'
    ctx2 = await pool.acquire()
    assert ctx1 is ctx2, 'Should reuse same context'
    await pool.close()
    print('OK: BrowserPool works')

asyncio.run(test())
