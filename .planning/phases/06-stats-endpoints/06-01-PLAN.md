  <name>Task 1: Create stats router with all endpoints</name>
  <files>api/v2/stats.py</files>
  <action>
Create api/v2/stats.py with FastAPI router implementing all stats endpoints:

1. Import dependencies: APIRouter from fastapi, ApiResponse from api.v2.response, SQLModel Session/func/select from sqlmodel, datetime/timedelta, core.db engine and models (TaskLog, AccountModel, AccountOverviewModel, ProxyModel)

2. Create router with prefix="/stats" and tags=["stats"]

3. Implement 5 endpoints:

GET /overview:
- Query TaskLog for total count, success count, failed count
- Query AccountOverviewModel for account distribution by lifecycle_status
- Query AccountModel for total_accounts
- Return ApiResponse(ok=True, data={total_registrations, success, failed, success_rate, total_accounts, account_distribution})

GET /by-platform:
- Query TaskLog grouped by platform, count successes and failures per platform
- Calculate success_rate per platform
- Return ApiResponse(ok=True, data=[{platform, total, success, failed, success_rate}, ...])

GET /by-day:
- Accept optional query params: days (default 30), platform (optional filter)
- Query TaskLog grouped by DATE(created_at), count successes and failures per day
- Filter by days parameter (created_at >= now - days)
- Filter by platform if provided
- Return ApiResponse(ok=True, data=[{date, total, success, failed}, ...])

GET /by-proxy:
- Query ProxyModel for all proxies
- For each proxy, calculate success_count, fail_count from TaskLog where proxy URL matches
- Return ApiResponse(ok=True, data=[{url, region, total, success, failed, success_rate}, ...])

GET /errors:
- Accept optional query params: days (default 30), platform (optional filter)
- Query TaskLog where status='failed', grouped by platform and error message
- Filter by days parameter
- Filter by platform if provided
- Return ApiResponse(ok=True, data=[{platform, error, count}, ...])

4. Follow existing pattern from api/v2/health.py: simple endpoint functions returning ApiResponse

5. All queries use synchronous Session(engine) context manager from core.db
